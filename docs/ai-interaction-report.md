# Отчёт о взаимодействии с ИИ-инструментами

## Задание и исходные данные

Для экспериментальной группы выбран слайд **Ironman** из файла `Marvel-Themed Merchandise Landing Page (Community).pix`. Размер фрейма и контрольного экспорта `assets/reference.png` — **1440 × 1024 px**. Цель: воспроизвести этот экран средствами HTML/CSS и проверить результат BackstopJS и Galen Framework.

## Использованные инструменты и фактические обращения

Работа выполнялась в SourceCraft Code Assistant. В проекте настроены MCP-серверы Pixso и Context7 (`.codeassistant/mcp.json`). Журнал сеанса SourceCraft фиксирует следующие вызовы:

| Сервер | Инструмент | Назначение |
|---|---|---|
| Pixso | `get_mcp_server_info` | Проверка соединения с локальным сервером |
| Pixso | `get_screenshot`, GUID `10:142` | Получение изображения выбранного фрейма |
| Pixso | `get_node_dsl`, GUID `10:142` | Получение структуры, размеров и стилей элементов |
| Pixso | `get_export_image`, GUID `10:165` и `10:164` | Экспорт отдельных графических элементов |
| Context7 | `resolve-library-id`, `query-docs` | Поиск документации BackstopJS |
| Context7 | `resolve-library-id` | Поиск документации Galen Framework |

В SourceCraft был передан запрос на реализацию слайда Ironman, создание сценариев BackstopJS и Galen и проверку результата. Текст задания для агента сохранён в `docs/sourcecraft-task.md`. По данным Pixso MCP и экспортированного PNG агент создал `index.html`, `styles.css`, дополнительные графические ресурсы, `backstop.json` и файлы Galen.

## Проверки и результат

SourceCraft запустил BackstopJS для экрана 1440 × 1024 px. Эталонный снимок соответствует `assets/reference.png`. Сохранены два фактических отчёта:

| Запуск | Доля несовпадающих пикселей | Итог |
|---|---:|---|
| `backstop_data/bitmaps_test/20261119-212200/report.json` | 14,03 % | `fail` |
| `backstop_data/bitmaps_test/20261119-215155/report.json` | 15,90 % | `fail` |

После первого сравнения агент изменил свечение и текстуру красной полосы, но повторная проверка показала увеличение расхождения. Следовательно, **попиксельное совпадение пока не достигнуто**. Последний снимок страницы и эталон находятся в `backstop_data/bitmaps_test/20261119-215155/` и `backstop_data/bitmaps_reference/`.

Сценарии Galen созданы в `galen/specs/ironman.gspec` и `galen/tests/ironman.test.js`. Успешный запуск Galen в журнале не подтверждён; установленный исполняемый файл `galen` также не найден при локальной проверке. Поэтому результат Galen нельзя считать проверенным.

При последующей подготовке проекта адреса страниц в конфигурации тестов заменены на локальный сервер `http://127.0.0.1:4173/`, чтобы сценарии не зависели от абсолютного пути на компьютере автора. Сохранённые выше отчёты относятся к прежним запускам и не подтверждают результат после этого изменения. Установка Galen через npm в текущем окружении не удалась из-за ошибки DNS `ENOTFOUND registry.npmjs.org`.

После просмотра снимка отчёта и данных Pixso направление градиента в `styles.css` скорректировано с `225deg` на `206.03deg`: в макете направление задано от правого верхнего к левому нижнему углу прямоугольника 500 × 1024 px.

Позднее студент запустил `npm run backstop:test` и прислал снимок вывода терминала: запуск `20261119-225831` завершился результатом **14,12 %**, `0 Passed`, `1 Failed` при пороге `0,1 %`. Это лучше предыдущих 15,90 %, но проверка всё ещё не пройдена. По снимку отчёта выделяется чрезмерно яркая овальная область свечения. Для следующей итерации в `.hero-glow` задана прозрачность `0.25`.

После изменения прозрачности студент повторил тест (`20261119-230228`) и прислал снимок вывода терминала: **11,88 %**, `0 Passed`, `1 Failed`. Снижение расхождения подтверждает, что свечение было одним из источников ошибки, однако до порога `0,1 %` ещё далеко.

Проба с прозрачностью `0.08` (`20261119-230616`) дала **12,99 %** и тоже завершилась неудачей. Эта настройка ухудшила результат по сравнению с `0.25`. Для следующей проверки была выбрана промежуточная прозрачность `0.5`.

Студент сообщил, что проверка с прозрачностью `0.5` дала **12,69 %**; значение возвращено к `0.25`, поскольку для него зафиксировано лучшее значение 11,88 %. Затем временное отключение слоя текстуры `.hero-noise`, по сообщению студента, также дало **12,69 %**. Слой текстуры снова включён. Эти два результата сообщены студентом в переписке; отдельные снимки терминала для них в данном отчёте не приложены.

## Трудности и вывод

В ходе работы SourceCraft неоднократно показывал ошибку соединения с провайдером (`OpenAI completion error: Connection error`) и повторно запрашивал разрешения на инструменты и команды. После сохранения файлов и двух запусков BackstopJS выполнение агента было остановлено. Полученный результат является рабочим прототипом и набором тестовых сценариев, но для выполнения критерия PixelPerfect требуются дальнейшая корректировка и повторные проверки.
